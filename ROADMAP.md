# Roadmap

## 0.1 — first usable vertical slice

- Deterministic core, safe Fedora/Windows collector plans, redaction, report/export, local cases, desktop workflow, tests, CI, and packaging scaffolding.

## Next recommended milestone: 0.2 platform hardening

- Validate Windows collectors and installers on Windows 11 x64.
- Validate Fedora 44 KDE live evidence across traditional and Atomic variants.
- Add cancellation propagation to running child processes and native save dialogs.
- Expand schema migration and corrupt-case recovery UX.
- Run an external security/privacy review with synthetic support bundles.

## Future candidates, not commitments

Additional explicitly tested OS versions and opt-in privileged collectors may be evaluated only after threat-model updates. AI diagnosis, repairs, remote access, cloud sync, accounts, unattended agents, and plugin marketplaces remain outside the planned trusted core.
