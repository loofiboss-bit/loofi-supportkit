# Windows collector inventory

The runtime uses fixed, non-interactive Windows PowerShell 5.1/CIM scripts for Windows version/build, update reboot state, PnP errors, stopped automatic services, disks, adapters, bounded recent system events, and GPU drivers. Renderer input never reaches script text.

Windows support is limited to Windows 11 x64. Live validation and installer signing are release gates and cannot be completed on Fedora.
