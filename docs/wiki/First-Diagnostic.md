# Run your first diagnostic

1. Select **Start a diagnostic**.
2. Choose the category closest to the problem. Use **General diagnostic scan** when the cause is unclear.
3. Review the collector summary and privacy option.
4. Select **Run read-only scan**.

![Problem category selection](https://raw.githubusercontent.com/loofiboss-bit/loofi-supportkit/main/docs/screenshots/new-diagnostic.png)

One unavailable collector does not abort the others. A partial result means that some evidence is unknown; it does not mean the missing area is healthy.

## Read findings

Findings are ordered by severity and include confidence, likely impact, next steps, and evidence references.

![Findings](https://raw.githubusercontent.com/loofiboss-bit/loofi-supportkit/main/docs/screenshots/findings.png)

Open an evidence reference when a support technician needs to connect the explanation to a record in the exported case. Then continue to [privacy review and export](Privacy-and-Exports).
