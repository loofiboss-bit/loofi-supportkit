# Loofi SupportKit 0.1.0

This is the first public release of the local-first diagnostics workflow.

## Included

- Bounded read-only collectors for Fedora KDE 44 x64 and Windows 11 x64.
- Deterministic findings with evidence references, confidence, impact, and next steps.
- Structured privacy redaction before persistence or export.
- Offline ZIP, HTML, and JSON support-case exports with checksums.
- Local case history with reopen and recovery actions.
- Fedora RPM and AppImage, plus Windows NSIS and portable executables.
- Fedora COPR updates, an illustrated user guide, and a GitHub Wiki.

## Install

- Fedora: `sudo dnf copr enable loofitheboss/loofi-supportkit && sudo dnf install loofi-supportkit`
- Windows: download the setup or portable executable below.

See the [installation guide](https://github.com/loofiboss-bit/loofi-supportkit/blob/v0.1.0/docs/INSTALLATION.md) before running a downloaded binary.

## Release status

Fedora KDE 44 packages and the local collector workflow were validated without elevation. Windows CI compiles, tests, and packages the Windows target, but the unsigned Windows artifacts have not yet completed physical Windows 11 live-collector validation. This limitation is intentionally visible rather than presented as a completed validation.
